# CaptionKit by Motionsfly

**AI captions + Text to Speech for Adobe After Effects & Premiere Pro** (Windows + macOS).

This repository delivers **CaptionKit updates**. The plugin checks `update.json` here
and shows an **Update** button inside the panel when a new version is out.
